Overview

Open Web Components is a glassmorphic web component library. Drop in one script tag and get beautiful, zero-dependency UI components that work in any framework.

API reference

Components expose attributes (move, resize, snap) and fire custom DOM events (o-click, o-change, o-input, o-results, o-select, o-sort, o-row-select).

Examples

See the full interactive demos on this page. Each section has copy-ready code snippets. Press ? for keyboard shortcuts.

Two independent axes A theme is a family (the visual language) crossed with a mode (the colour scheme). All six combinations work:

Families: glass, pixel, office  ×  Modes: light, dark

Geometry — radii, blur, font, border width — belongs to the family and never changes with mode, so toggling light/dark cannot move a pixel.

Whole page — one or both attributes:
<body data-owc-theme="office" data-owc-mode="dark">

Single component — always wins over the page:
<o-button theme="pixel" mode="light">OK</o-button>
mode on its own keeps the page's family and swaps only its palette.

With no mode set, the mode follows the visitor's OS (prefers-color-scheme). An explicit mode always beats the OS.

Legacy names theme="light" and theme="dark" shipped in v1.0 and still work — they are pinned aliases for glass + light and glass + dark.

Contrast Every family × mode is checked against WCAG AA by the test suite: body text at 4.5:1 and decorative text, accents and scrollbars at 3:1, measured by compositing each translucent layer over the one beneath it.

CSS custom properties Colours: --glass-bg, --glass-border, --glass-hover, --glass-text, --glass-text-muted, --glass-text-dim, --accent-warm, --glass-accent-text.
Depth: --glass-blur, --glass-backdrop, --glass-shadow, --glass-elevation, --glass-scrim.
Geometry: --glass-border-width, --glass-radius (plus -xs / -sm / -md / -lg / -xl / -2xl / -pill).
Page chrome: --glass-page-bg, --glass-page-text, --glass-chrome-bg, --glass-chrome-border.
Type & motion: --glass-font, --glass-press.

Set any of these on an ancestor prefixed with --owc- (e.g. --owc-glass-radius: 0) to patch a theme page-wide.

asyncPlus

asyncPlus(...promises) wraps multiple promises and automatically drives the progress bar — starts on the first call, increments as each settles, completes when all are done. Fires a progress-complete event on document.

// Two o-search bars — results must satisfy both filters simultaneously
s1.addEventListener('o-input', e => { q1 = e.detail.query; render() })
s2.addEventListener('o-input', e => { q2 = e.detail.query; render() })

function render() {
  const a = q1.toLowerCase(), b = q2.toLowerCase()
  table.data = allData.filter(r =>
    (!a || r.name.toLowerCase().includes(a) || r.dept.toLowerCase().includes(a)) &&
    (!b || r.company.toLowerCase().includes(b))
  )
}
